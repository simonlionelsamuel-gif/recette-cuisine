Première ouverture sur ce téléphone : relie l’app à votre liste privée. À faire une seule fois.

Créer le jeton d’accès (3 minutes, une seule fois pour vous deux)
  1. Ouvre github.com/settings/personal-access-tokens/new dans le navigateur.
  2. Token name : Nos courses. Expiration : la plus longue proposée.
  3. Repository access : Only select repositories, puis choisis recette-cuisine-data.
  4. Permissions → Repositories → Contents : Read and write.
  5. Generate token, puis copie le jeton (il commence par github_pat_).

Le jeton reste uniquement sur ce téléphone. Il ne donne accès qu’au dépôt privé de la liste.
