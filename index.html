Nos courses

Première ouverture sur ce téléphone. À faire une seule fois.

Pas d’invitation ? Créer le jeton d’accès (une seule fois, sur le premier téléphone)
  1. Ouvre github.com/settings/personal-access-tokens/new dans le navigateur.
  2. Token name : Nos courses. Expiration : une durée de la liste (pas « Custom »).
  3. Repository access : Only select repositories, puis choisis recette-cuisine-data.
  4. Permissions → Repositories → Contents : Read and write.
  5. Generate token, puis colle le jeton (il commence par github_pat_) dans le champ ci-dessus.

Ensuite, invite l’autre personne depuis ⚙ Réglages → Inviter quelqu’un.

L’accès reste uniquement sur ce téléphone. Il ne donne accès qu’au dépôt privé de vos listes.
